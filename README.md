# Loadout Legends Sync

Loadout Legends Sync is the complete Windows companion app for
[Loadout Legends](https://www.loadoutlegends.com/), built specifically for EverQuest Legends.

## Download

[Download the latest version](https://github.com/Legendaddy1216/LoadoutLegendsSyncReleases/releases/latest)
and run the Windows setup file.

## Included tools

- Automatic gear and character-stat syncing for every loadout.
- **[EverQuest Legends DPS Parser and Overlay](https://www.loadoutlegends.com/parsing-tools)** with
  session and encounter breakdowns, pet assignment, and automatic best raid DPS and time-to-kill
  uploads.
- Player profiles and leaderboards for comparing gear and raid performance.
- Spell timer overlay, Spellblade proc-rate calculator, and spell-resist tracking.
- Player-built item, mob, and drop database that improves as the community syncs.
- Automatic Plane of Sky quest tracking.

The DPS parser and overlay are included in the full Loadout Legends Sync application. They are not
a separate download.
